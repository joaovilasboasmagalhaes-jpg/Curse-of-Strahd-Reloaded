# Sister Elga: Document Guide

This directory contains reference material and campaign-planning notes related to Sister Elga.

## Reference Documents

These documents record established character information and mechanics.

- [Backstory](backstory.md): The character backstory submitted by the player to the Dungeon Master (DM).
- [Plot Hook](plot_hook.md): The DM-provided account of how Sister Elga enters the campaign.
- [Soul Gathering](soul_gathering.md): The rules and mechanics for Sister Elga's soul-gathering ability.

## Campaign Planning

These documents are intended to evolve as the campaign develops.

- [DM Plans](dm_plans.md): Plans for incorporating the player's backstory into the campaign.
- [Rahadin](rahadin.md): Notes on possible connections between Rahadin's history and powers, Sister Elga's abilities, and the church's history.
- [The Silent Cloister](silent_cloister.md): The lost monastery in Barovia, including its history, layout, NPCs, and encounters.
