# Caspian: Document Guide

This directory contains reference material and campaign-planning notes related to Caspian.

## Reference Documents

These player-accessible documents record Caspian's established background, knowledge, and mechanics.

- [Backstory](backstory.md): The character backstory submitted by the player to the Dungeon Master (DM), including his connection to the opening session.

## Campaign Planning

These DM-only documents contain mutable plans for connecting Caspian's backstory to Barovian lore.

- [DM Plans](dm_plans.md): Mutable DM canon for Ashcairn, the Order of the Blades academy, the Northern Pack raid that destroyed Caspian's home, and the raid's leader, Ravka Ashclaw.
- [Campaign Integration](dm_campaign_integration.md): Mutable campaign-facing consequences, act-by-act DM hooks, the shared throughline with Ivan's Arc L/Arc Q, and Ravka's boss encounter.
