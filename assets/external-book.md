# External Books Index

Reference library for the campaign (DM use). Digests of the most useful books are in [.github/skills/dm-craft/books/](../.github/skills/dm-craft/books/), indexed by the [dm-craft skill](../.github/skills/dm-craft/SKILL.md). Other books are judged from titles and sizes only.

Files are `.epub` unless marked `.pdf`.

## Most useful for Curse of Strahd

| File | Use | Digest |
|---|---|---|
| `vampires_adamsmedia.epub` | Vampire folklore and tropes. Best thematic fit for Strahd, his court and Elga's undead material. | [vampires](../.github/skills/dm-craft/books/vampires.md) |
| `ultimaterpgcharacterbackstoryguide.epub` | Making and using player backstories. Feeds `players/<name>/concepts` and backstory integration. | [backstory-guide](../.github/skills/dm-craft/books/backstory-guide.md) |
| `ultimaterpgcharacterbackstoryguide_expandedgenresedition.epub` | Same, with extra genres (check for gothic horror). | [backstory-guide](../.github/skills/dm-craft/books/backstory-guide.md) |
| `ultimaterpggameplayguide.epub` | Running RPGs, table dynamics, spotlight balance. | [gameplay-guide](../.github/skills/dm-craft/books/gameplay-guide.md) |
| `ultimaterandomencountersbook.epub` | Random encounters to reskin for Barovian travel (Mists, gloom). | none |
| `Van Richtens Guide to the Vistani (David Wise)….pdf` | Ravenloft (AD&D 2e) sourcebook on the Vistani: culture, customs, Vistani NPCs. Check against the guide's own Vistani before using; the guide overrides it. | [vistani](../.github/skills/dm-craft/books/vistani.md) |
| `Van Richtens Guide to Werebeasts (Nigel Findley)….pdf` | Ravenloft (AD&D 2e) sourcebook on lycanthropy and werebeasts. Useful for the werewolves, and check against `barovia-rules-reference` for lycanthropy. | [werebeasts](../.github/skills/dm-craft/books/werebeasts.md) |
| `The Monsters Know What Theyre Doing (Keith Ammann)….epub` | How monsters should think and fight in tactical combat. Directly supports the `combat` skill (fights with objectives, not HP races). | [monsters-know](../.github/skills/dm-craft/books/monsters-know.md) |
| `Sly Flourishs Return of the Lazy Dungeon Master (Michael E. Shea)….epub` | Efficient session prep. Supports the `session-prep` pipeline. | [lazy-dm](../.github/skills/dm-craft/books/lazy-dm.md) |
| `The Ultimate RPG Villain Backstory Guide (James D'Amato, Dillin Apelyan)….epub` | Building compelling villains and antagonists. Useful for Strahd and his lieutenants, and for villain backstories. | [villain-guide](../.github/skills/dm-craft/books/villain-guide.md) |
